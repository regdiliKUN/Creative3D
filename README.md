# Creative3D · 3D 建模创意生成器 v3

[![Python](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-lightgrey.svg)](https://www.microsoft.com/windows)
[![Offline](https://img.shields.io/badge/network-not%20required-brightgreen.svg)](#)

一个**完全离线**的 Windows 桌面工具：把一句话变成可 3D 打印的实体模型。

```
"一只坐着的猫，圆润一点，高 120mm，打印级"
            │
            ▼
   提示词编译器 ──► 概念配方 ──► SDF 距离场 ──► 网格化 ──► 打印体检 ──► STL / 3MF / OBJ / PNG / 创意卡
   (词 → 模型/风格/尺寸/精度)   (59 个可组合配方)   (任意图元布尔)   (Surface Nets)   (水密/悬垂/摆放)
```

---

## ✨ v3 做了什么

v2 只能生成 8 个写死的参数化形态。v3 换成了一套**距离场（SDF）建模内核 + 概念配方库**：

| | v2 | v3 |
| --- | --- | --- |
| 能做什么 | 8 个固定形态 | **59 个概念模型**，任意提示词都有结果 |
| 造型方式 | 每个形态手写三角网格 | 图元布尔 / 平滑并集 / 噪声位移 / 阵列，自由组合 |
| 精度 | 一根「细节密度」滑杆 | **5 档精度**（草稿→打印级），每档标明面数与体积 |
| 尺寸 | 固定 100mm | **任意目标尺寸（20–400mm）**，导出即真实尺寸 |
| 工艺 | 无 | **中空 + 壁厚**、按精度自动加厚、自动摆正 |
| 打印前 | 无 | **打印体检**：水密性 / 体积 / 重量 / 悬垂 / 摆放建议 |
| 导出 | STL / OBJ / PNG / MD | 追加 **3MF**（带单位）与**体检报告** |

## 🚀 使用

### 直接运行
双击 `3D建模创意生成器.exe`。

### 从源码运行
```bash
pip install numpy pillow
cd src
python run.py
```

### 三步上手
1. **写一句话**：`齿轮 高 80mm 打印级 尖锐` —— 模型、尺寸、精度、风格一次说清。
   没写清楚也没关系，模型库里 59 个模型点一下就换。
2. **调精度与工艺**：精度档位决定面数；中空 + 壁厚决定用料；风格开关（圆润 / 硬朗 /
   粗糙 / 扭曲 / 繁复 / 极简）随时叠加。
3. **看体检、导出**：右栏「打印体检」给出水密性、体积、克重、悬垂占比与建议摆放，
   点「摆正」自动挑最省支撑的朝向，然后导出 STL/3MF 进切片软件。

## 🧠 技术要点

### 1. SDF 建模内核（`sdf.py`）
球 / 椭球 / 盒 / 圆柱 / 圆台 / 胶囊 / 圆环 / 棱柱 / 半空间，2D 图元与挤出、旋转，
布尔与平滑并集、抽壳、域扭曲、噪声位移、极坐标阵列、刻面切割……
全部是「接收点集、返回距离」的纯 numpy 函数，因此可以任意嵌套组合。

**旋转体用的是精确距离场**（剖面折线 + 半径判内外），而不是「一堆圆台求并集」——
后者在实体内部会被图元自身的内部面污染，一抽壳就会在壁中间冒出假表面。

### 2. 网格化（`sdfmesh.py`）
用 **Surface Nets**（对偶等值面）而不是 Marching Cubes：每个跨越表面的体素只放一个顶点，
天然封闭、天然流形、顶点更省。精度靠四件事保证：
1. 两遍采样：先粗采样定位包围盒，再把网格分辨率全部花在有效区域上；
2. 顶点放在「12 条棱与表面交点」的质心，而不是体素中心；
3. Taubin 平滑（λ/μ 交替）去阶梯感且不缩体积；
4. 牛顿投影：沿梯度把顶点推到真正的零等值面上（球体的半径误差 < 1e-4）。

退化兜底：三组亚体素偏移 + 亚体素侵蚀重试，取问题最少的一版。

### 3. 概念配方库（`concepts.py`）
每个模型都是若干图元的装配，共享同一套「风格旋钮」（圆润度 / 锐度 / 粗糙度 / 扭曲）。
因此加一个新模型只要写十几行，就自动获得全部精度、尺寸、中空、风格能力。

### 4. 打印体检（`printcheck.py`）
水密性、包围盒、体积、PLA/树脂克重、45° 判据下的悬垂面积占比、底部接触面，
并在 8 个正交朝向里挑悬垂最少、最矮的那个作为建议摆放。

## 📁 项目结构

```
Creative3D/
├── 3D建模创意生成器.exe      # 单文件可执行程序
├── 使用说明.md
├── legacy_v1/                # v1 旧包体备份
├── exports/                  # 默认导出目录
└── src/
    ├── run.py
    ├── 3D建模创意生成器.spec  # PyInstaller 打包配置
    ├── creative3d/
    │   ├── sdf.py            # SDF 图元与组合算子
    │   ├── sdfmesh.py        # Surface Nets 网格化 + 后处理
    │   ├── concepts.py       # 59 个概念配方
    │   ├── quality.py        # 精度档位
    │   ├── printcheck.py     # 打印体检与自动摆正
    │   ├── nlp.py            # 提示词编译器
    │   ├── repair.py         # 非流形修复
    │   ├── generators.py     # v2 的 8 个经典形态（保留）
    │   ├── registry.py       # 经典形态登记表
    │   ├── mesh.py           # 网格数据结构 / STL / OBJ
    │   ├── render.py         # 渲染管线（预览与导出共用）
    │   ├── session.py        # 单一状态源（概念 / 经典双通道）
    │   ├── exporter.py       # STL / 3MF / OBJ / PNG / MD / 体检报告
    │   └── ui/               # 主题 / 控件 / 视口 / 面板 / 对话框
    ├── tests/                # test_core.py（102 项）+ test_sdf.py（53 项）
    └── tools/                # 截图 / 布局体检 / 概念总览图
```
